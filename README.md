# Эволюционное программирование и генетические алгоритмы — комплекс лабораторных работ

НИЯУ МИФИ, группа 517, номер в списке группы $N = 3$, 2026 год.

**Вариант:** $V = 1 + ((17 \cdot 3 + 7 \cdot 1 + 26) \bmod 20) = 5$, размерность для ЛР1 $d = 5 + (5 \bmod 6) = 10$.
Подробно — [`docs/variant.md`](docs/variant.md); конспект ТЗ — [`docs/task.md`](docs/task.md).

Все ключевые эволюционные операторы реализованы самостоятельно:
- инициализация, селекция, кроссовер, мутация, элитизм;
- ремонт и штрафы;
- недоминируемая сортировка, crowding distance, гиперобъём;
- операторы генетического программирования.

Готовые оптимизаторы (DEAP, pymoo, scipy.optimize и т. п.) не используются. Библиотеки: `numpy` — только векторы и ГПСЧ, `matplotlib` — графики, `pytest` — тесты.

## Быстрый старт

Нужен Python ≥ 3.11 (конфиги читаются стандартным `tomllib`). Все команды выполняются из корня репозитория.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest          # 60 тестов, < 1 с
```

Полное воспроизведение всех экспериментов:

```bash
# ЛР1 (~6 с)
.venv/bin/python -m lab1.main --config lab1/configs/*.toml && .venv/bin/python -m lab1.analyze --plots

# ЛР2 (~40 с)
.venv/bin/python -m lab2.exact && .venv/bin/python -m lab2.main --config lab2/configs/*.toml
.venv/bin/python -m lab2.analyze --plots && .venv/bin/python -m lab2.examples

# ЛР3 (~75 с)
.venv/bin/python -m lab3.main --config lab3/configs/*.toml && .venv/bin/python -m lab3.analyze --plots

# ЛР4 (~10 мин)
.venv/bin/python -m lab4.main --config lab4/configs/gp_depth.toml lab4/configs/gp_parsimony.toml \
    lab4/configs/gp_tarpeian.toml lab4/configs/gp_nsga2.toml lab4/configs/gp_depth_k2.toml
.venv/bin/python -m lab4.analyze --plots
```

Отдельная серия со своим seed и числом запусков:

```bash
.venv/bin/python -m lab1.main --config lab1/configs/ga_base.toml --seed 42 --runs 20
```

Подробные инструкции — в `labN/README.md`.

## Где что искать (соответствие требованиям ТЗ)

| требование ТЗ (п. 1.2–1.3) | где выполнено |
|---|---|
| seed фиксирован и задаётся параметром запуска | `seed` в каждом `labN/configs/*.toml`; флаги `--seed`, `--runs`; запуск $i$ использует `seed + i` |
| серия независимых запусков | 20 запусков в ЛР1–3, 30 в ЛР4 |
| все параметры указаны явно | `labN/configs/*.toml`: популяция, бюджет, вероятности, параметры мутации, критерий остановки, обработка ограничений, инициализация |
| фактически использованные параметры | `labN/results/*_config.json` |
| результаты серий в машиночитаемом виде | `labN/results/*_summary.csv` (строка на запуск), `*_gens.csv` (агрегаты по поколениям) |
| сводная статистика | `labN/results/summary.md`: best / mean / median / std / worst, доля допустимых, время, число вызовов ФФ, U-тест Манна—Уитни |
| графики | `labN/results/*.png`, вставлены в отчёты |
| входные данные и процедура генерации | `lab2/data`, `lab3/data`, `lab4/data` + `generate_data.py` / `data.py` с фиксированным seed |
| README с командой запуска | `labN/README.md` |
| отчёт | `labN/REPORT.md` |
| тесты операторов | `tests/` (ядро) и `labN/tests/` |

Параметры операторов подбирались на отдельных seed (ЛР1: 0–9, ЛР2: 0–9, ЛР3: 0–4, ЛР4: 100–102). Итоговые серии запускались на других seed (1000+, 2000+, 3000+, 4000+), так что настройка отделена от проверки. Сравнение алгоритмов везде идёт при одинаковом бюджете вычислений ФФ.
