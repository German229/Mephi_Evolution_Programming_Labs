# ЛР3 (трек A): многокритериальная настройка режима полива — собственный NSGA-II (вариант 5)

Решение — расписание полива на 30 суток (30 суточных норм, 0–25 мм). Качество оценивается симуляцией
водного баланса почвы на ансамбле из 10 сценариев осадков (расписание составляется заранее, дождь неизвестен).
Критерии (минимизация): расход воды; средний дефицит влаги (водный стресс); среднее переувлажнение.

## Запуск (из корня репозитория; установка — см. `lab1/README.md`)
```bash
# прогноз ET0 и 10 сценариев осадков (уже лежит в data/, пересоздаётся тем же seed)
.venv/bin/python -m lab3.generate_data --seed 2026

# все серии (5 конфигураций × 20 запусков), ~75 с (из них ~45 с — свёртка с 10× бюджетом)
.venv/bin/python -m lab3.main --config lab3/configs/*.toml

# одна серия со своим seed
.venv/bin/python -m lab3.main --config lab3/configs/nsga2.toml --seed 42 --runs 20

# гиперобъём, U-тесты, проекции фронта, характерные решения
.venv/bin/python -m lab3.analyze --plots

.venv/bin/python -m pytest lab3 tests/test_moo.py
```

## Конфигурации (`configs/`)
| файл | назначение |
|---|---|
| `nsga2.toml` | NSGA-II: популяция 100, 20 000 вызовов, SBX (η_c = 15), полиномиальная мутация (η_m = 20) |
| `nsga2_eta5.toml` | один фактор: η_m = 5 |
| `weighted_sum.toml` | взвешенная свёртка: 10 векторов весов × 2 000 вызовов (тот же общий бюджет) |
| `weighted_sum_10x.toml` | взвешенная свёртка с бюджетом 20 000 на каждый вектор (в 10 раз больше) |
| `random_search.toml` | случайный поиск с архивом недоминируемых, 20 000 вызовов |

## Файлы
- `model.py` — модель водного баланса и критерии; `operators.py` — SBX и полиномиальная мутация.
- `nsga2.py` — NSGA-II, взвешенная свёртка, случайный поиск.
- `../evo_core/moo.py` — недоминируемая сортировка, расстояние скученности, турнир, точный гиперобъём (2D/3D).
- `results/`: `*_summary.csv` (HV по запускам), `*_gens.csv` (HV по поколениям), `*_fronts.csv` (итоговые фронты всех
  запусков), `*_median_front.csv` (фронт и расписания запуска с медианным HV), `summary.md`, `*.png`.
